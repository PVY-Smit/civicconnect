# Architecture Decision Records

From Milestone 2. One file per decision, named `ADR-NNN-short-title.md`, numbered in the
order taken and never renumbered.

The Decision Log sheet in the registers workbook is the index. An ADR is written where a
decision needs more room than a register row: major architecture, technology, persistence,
integration, authentication, deployment and infrastructure choices.

Each record carries: context, constraints, alternatives considered, the decision, the
rationale, the trade-offs accepted, the risks created, the evidence, and a later-consequence
section updated when evidence emerges.

Four decisions are already recorded as deliberately deferred to M2 in the Decision Log:
DEC-008 technology stack, DEC-009 architecture style, DEC-010 deployment platform,
DEC-011 persistence design. Each states the evidence still required. Those become ADRs when
they are taken.
